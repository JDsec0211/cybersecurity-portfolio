# Cybersecurity Portfolio

Hi, I'm **Jesus Davila**, a Cybersecurity & Digital Forensics (BAS) student at Highline College and VP of the Highline Cybersecurity Club.

This repository collects hands-on projects I completed for the **Google Cybersecurity Professional Certificate**. Each one is based on a realistic workplace scenario: auditing a company's security controls, analyzing network traffic to find the cause of an incident, and writing up findings the way an analyst would for a team.

---

## 📁 Projects

| # | Project | What I did | Skills & tools |
|---|---------|------------|----------------|
| 01 | [DNS & ICMP Traffic Analysis](01_Network-Traffic-Analysis/) | Analyzed a tcpdump capture to find out why users couldn't reach a website, and traced the failure to the DNS service on UDP port 53 | tcpdump, packet analysis, DNS, UDP, ICMP, incident reporting |
| 02 | [Botium Toys Security Audit](02_Security-Audit/) | Assessed a small company's administrative, technical, and physical controls and checked compliance with PCI DSS, GDPR, and SOC | Security controls, risk assessment, PCI DSS, GDPR, SOC |
